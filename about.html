关于青阅书城

读万卷书，行万里路。

青阅书城（QingYue Bookstore）诞生于 2026 年校园实训课堂，是一个集图书商城、数据可视化、创意画板与视听体验于一体的数字阅读服务平台。我们相信，每一本好书都是一扇通往新世界的门。

从“结构-样式-行为”分离的工程化开发，到 Vue3 响应式组件、Element Plus 组件库、ECharts 数据可视化与 Axios 远程 API 的融合应用，青阅书城不仅是一个作品，更是一次对 Web 前端全栈能力的完整实践。

常见问题 FAQ

图书数据存在哪里？刷新会丢失吗？

所有图书数据以 JavaScript 对象内置在 js/data.js 中，购物车、收藏、浏览记录、订单与用户数据通过 localStorage 持久化保存，刷新页面不会丢失。

为什么需要登录才能收藏和下单？

收藏与订单与用户账号绑定，登录后可跨页面、跨会话查看自己的收藏夹与订单记录，实现“存储→读取→修改→删除”的完整数据闭环。

网站支持移动端访问吗？

支持。全站采用 Flexbox 与 Grid 响应式布局，并针对 992px / 640px 断点优化导航折叠、卡片排布与表单控件，手机、平板均可正常浏览。

第三方库全部离线可用吗？

Vue3、Element Plus、ECharts、Axios、Font Awesome 通过 CDN 引入，需要联网加载；核心业务逻辑全部为原生 HTML/CSS/JavaScript 实现，页面结构离线可访问。
